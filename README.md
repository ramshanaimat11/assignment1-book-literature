# Book & Literature Club

## Project Description
A website for a Book & Literature Club where visitors can
discover literary events and register for activities.

## Website Pages
- Home: Introduction to the club
- Events: Upcoming book and literature events
- Register: Registration form for club activities

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
Open index.html in a web browser.
